## 实例 1：搭建练习营地

🎯 **练什么**：建目录、看路径、列文件（含隐藏）
📝 **任务**：在 `lab/` 下建三层结构 `lab/docs/`、`lab/data/`、`lab/scripts/`，在里面藏一个隐藏文件，然后确认位置。

💡 **思路**：
1. `mkdir` 一次建多层（想想要加什么参数）
2. 创建隐藏文件（隐藏 = 文件名以什么开头？）
3. `pwd` 看绝对路径，`ls` 看文件——为什么 ls 看不到隐藏文件？

🔧 **参考**：
```bash
mkdir -p lab/docs lab/data lab/scripts
touch lab/docs/.hidden
pwd
ls -la lab/docs    # -a 才会显示 .hidden
```

✅ **自查**：`ls -la lab/docs` 能看到 `.hidden`；`pwd` 输出的是完整绝对路径。

## 实例 2：会说话的文件名（空格与引号）

🎯 **练什么**：空格文件名必须加引号
📝 **任务**：创建 `my notes.txt`（两行内容）和 `lab report.txt`（空文件），再读回来看内容。

💡 **思路**：
1. 先试试**不加引号**会怎样（预期报错）——体会为什么
2. 加引号创建带空格文件
3. `cat` 读回内容，同样要加引号

🔧 **参考**：
```bash
printf 'line one\nline two\n' > "my notes.txt"
touch "lab report.txt"
cat "my notes.txt"
ls -la          # 能看到两个带空格的文件
```

✅ **自查**：`cat "my notes.txt"` 输出两行；`ls` 里文件名带空格正常显示。

## 实例 3：复制搬家（保留目录结构）

🎯 **练什么**：`find` + `cp --parents` 批量复制且保留相对目录
📝 **任务**：在 `lab/docs/` 下建 `a.txt`、`b.txt` 和子目录 `sub/c.txt`，把**所有 .txt** 复制到 `lab/backup/`，要求 `backup/docs/sub/c.txt` 这个结构完整保留。

💡 **思路**：
1. `find` 找出所有 .txt（用什么 -name 参数？）
2. `-exec cp --parents {} 目标/ \;` 复制
3. **关键**：先 `cd` 到哪一层，复制出来的结构才不带 `lab/` 前缀？

🔧 **参考**：
```bash
mkdir -p lab/docs/sub
touch lab/docs/a.txt lab/docs/b.txt lab/docs/sub/c.txt
cd lab
find docs -name '*.txt' -exec cp --parents {} backup/ \;
cd ..
find lab/backup -type f    # 应看到 docs/a.txt docs/b.txt docs/sub/c.txt
```

✅ **自查**：`lab/backup/docs/sub/c.txt` 存在；复制后原文件还在。

## 实例 4：权限门卫与清单

🎯 **练什么**：按类型设权限 + 生成文件清单
📝 **任务**：对 `lab/backup/` 设权限：**目录 755、普通文件 644**；然后生成 `inventory.txt`，每行格式"相对路径 字节数"。

💡 **思路**：
1. 目录和文件要**分开**设置，用什么参数区分类型？
2. 字节数用什么 find 格式符？（`%p` 路径，`%s` 是什么？）
3. 输出要排序，用什么管道？最后重定向到文件

🔧 **参考**：
```bash
cd lab/backup
find . -type d -exec chmod 755 {} \;
find . -type f -exec chmod 644 {} \;
find . -type f ! -name inventory.txt -printf '%p %s\n' | sort > inventory.txt
```

✅ **自查**：`ls -la` 目录显示 `drwxr-xr-x`（755）、文件 `-rw-r--r--`（644）；inventory.txt 每行是"路径 数字"。

## 实例 5：日志流水线初体验

🎯 **练什么**：管道 `|` 串联三个工具
📝 **任务**：创建 `server.log`（10 行，每行"时间 状态码"），取出**最后 5 行**、按**字典序排序**、只要**前 3 行**。

💡 **思路**：
1. 一个工具干一件事，用 `|` 连起来：先想"取最后5行"用什么？
2. 排序用什么？取前3行用什么？

🔧 **参考**：
```bash
seq 1 10 | awk '{print "0"$1":00 " (($1%3==0)?"500":"200")}' > server.log
tail -n 5 server.log | sort | head -n 3
```

✅ **自查**：输出恰好 3 行，且是最后 5 行排序后的前 3 个。

## 实例 6：awk 认列

🎯 **练什么**：awk 按列处理 + 跳过表头
📝 **任务**：创建 `score.csv`（表头 `name,score` + 4 行数据），用 awk 输出"姓名 分数"两列，并输出**总人数**。

💡 **思路**：
1. 按逗号分列用什么参数？（`-F','`）
2. 第1列、第2列怎么引用？（`$1` `$2`）
3. 表头怎么跳过？（awk 内置行号变量是啥？）
4. 统计人数：每行数据 +1，最后在 `END{}` 里输出

🔧 **参考**：
```bash
printf 'name,score\nAlice,90\nBob,85\nCarol,95\nDave,88\n' > score.csv
awk -F',' 'NR>1 {print $1, $2; n++} END {print "total:", n}' score.csv
```

✅ **自查**：输出 4 行"姓名 分数" + `total: 4`；表头 `name,score` 没被打印。

## 实例 7：谁是最强王者（统计）

🎯 **练什么**：正则匹配 + 计数 + 多键排序（第2题核心）
📝 **任务**：`access.csv`（timestamp,user,path,status,latency_ms）里，统计 **5xx 次数最多的前 2 个 path**，次数降序、同次数按 path 字典序。

💡 **思路**（这就是第2题那道题的完整思路）：
1. 跳过表头：`tail -n +2`
2. 过滤 5xx：awk 判断第4列，用什么正则？（`~ /^5/`，想想为什么不是 `=="500"`）
3. 计数：`sort | uniq -c` 还是 awk 数组？任选
4. 排序：次数降序+字典序 = `sort -k1,1nr -k2,2`（解释：k1 数值降序，k2 字典序）
5. 取前2：`head -n 2`

🔧 **参考**：
```bash
tail -n +2 access.csv | awk -F',' '$4 ~ /^5/ {print $3}' \
  | sort | uniq -c | sort -k1,1nr -k2,2 | head -n 2
```

✅ **自查**：输出第一行次数 ≥ 第二行；同次数时 path 按字母序。

## 实例 8：脚本小作坊（健壮性）

🎯 **练什么**：写一个带"防御"的脚本（第2题收尾）
📝 **任务**：写 `stats.sh`：接收 CSV 路径参数；文件不存在时**错误写 stderr 并退出 1**；存在时输出所有行第2列（score）的**平均分，保留两位小数**。

💡 **思路**：
1. 参数怎么取？（`$1`）
2. 判断文件不存在怎么写？（`[ ! -f "$1" ]`）
3. 错误输出到 stderr 用什么？（`>&2`）
4. 平均分：awk 累加+计数，`NR>1` 跳过表头，`printf "%.2f"` 格式化

🔧 **参考**：
```bash
#!/bin/bash
f="$1"
if [ ! -f "$f" ]; then
    echo "Error: $f not found" >&2
    exit 1
fi
awk -F',' 'NR>1 {s+=$2; n++} END {printf "%.2f\n", s/n}' "$f"
```

✅ **自查**：`bash stats.sh score.csv` 输出平均分；`bash stats.sh nope.csv; echo $?` 输出错误且 `$?` 是 1。

## 实例 9：Git 第一次亲密接触

🎯 **练什么**：从零建仓库并提交
📝 **任务**：在 `repo1/` 建 Git 仓库，创建 `hello.txt`（两行内容），提交一次，查看状态和历史。

💡 **思路**：
1. 进目录后 `git init`
2. 先设置身份（`git config user.name/email`，不然提交会失败——想想之前我们怎么设置的）
3. 写文件 → `git add` → `git commit -m "说明"`
4. `git status` 看是否干净，`git log --oneline` 看历史

🔧 **参考**：
```bash
mkdir repo1 && cd repo1
git init
git config user.name "陆立庭"
git config user.email "你的邮箱"
printf 'hello world\nsecond line\n' > hello.txt
git add hello.txt
git commit -m "init: hello.txt"
git status
git log --oneline
```

✅ **自查**：`git status` 显示 working tree clean；`git log` 有一条记录。

## 实例 10：分叉之路（分支与合并冲突）

🎯 **练什么**：制造并解决合并冲突（第3题全流程）
📝 **任务**：main 上 `version.txt` 内容 `v1` 提交；分支 `dev-a` 改成 `v2` 提交；**从初始 main** 建分支 `dev-b` 改成 `v3` 提交；回 main 先合并 dev-a 再合并 dev-b，解决冲突保留 `v2` 并加一行 `note=reviewed`。

💡 **思路**：
1. 为什么要"从初始 main"建 dev-b？（答：合并时才有冲突）
2. 冲突后文件里会出现什么标记？（`<<<<<<<` `=======` `>>>>>>>`）
3. 解决 = 编辑文件 → `git add` → `git commit`，三步缺一不可

🔧 **参考**：
```bash
git init && git config user.name "陆立庭" && git config user.email "你的邮箱"
printf 'v1\n' > version.txt && git add version.txt && git commit -m "init: v1"
git checkout -b dev-a && printf 'v2\n' > version.txt && git add . && git commit -m "dev-a: v2"
git checkout main && git checkout -b dev-b && printf 'v3\n' > version.txt && git add . && git commit -m "dev-b: v3"
git checkout main && git merge dev-a
git merge dev-b        # 冲突！
printf 'v2\nnote=reviewed\n' > version.txt
git add version.txt && git commit -m "merge dev-b, keep v2"
git log --all --graph --decorate --oneline
```

✅ **自查**：`version.txt` 内容是 `v2` + `note=reviewed`；`git log --graph` 有分叉和合并点；`git status` 干净。

## 实例 11：第一份中文文档

🎯 **练什么**：LaTeX 中文文档 + 命令行编译
📝 **任务**：写 `welcome.tex`：中文文档类，标题"我的第一份 LaTeX 报告"，作者你的名字，两个章节（第一节写一句话，第二节写一句话），编译出 PDF。

💡 **思路**：
1. 中文文档类是什么？（`\documentclass[UTF8]{ctexart}`）
2. 标题三件套：`\title` `\author` `\maketitle`
3. 章节：`\section{...}`
4. 编译：为什么必须 `latexmk -xelatex` 而不是 `-pdf`？（答：中文）

🔧 **参考**：
```latex
\documentclass[UTF8]{ctexart}
\title{我的第一份 LaTeX 报告}
\author{陆立庭}
\date{\today}
\begin{document}
\maketitle
\section{介绍}
这是用中文文档类写的第一份报告。
\section{下一步}
继续学习公式和表格。
\end{document}
```
```bash
latexmk -xelatex -halt-on-error welcome.tex
```

✅ **自查**：welcome.pdf 打开中文正常显示；`grep '??' welcome.log` 无输出。

## 实例 12：报告的灵魂（公式表格与交叉引用）

🎯 **练什么**：公式、表格、label 引用（第4题核心）
📝 **任务**：在实例 11 基础上加：一个带 label 的公式（如 $E=mc^2$）、一个 2×2 表格（带 caption 和 label），正文里用 `\eqref` 引用公式、用 `\ref` 引用表格，编译后无 `??`。

💡 **思路**：
1. 公式环境是 `equation`（不是 `$...$`，那个不编号），加 `\label{eq:xxx}`
2. 表格：`table` 环境里放 `tabular`，`\caption` + `\label`
3. 正文引用：公式用 `\eqref`（需要 amsmath），表格用 `Table \ref`
4. `\eqref` 依赖哪个宏包？别忘了 `\usepackage{amsmath}`

🔧 **参考**：
```latex
\usepackage{amsmath}
...
质能方程 \eqref{eq:energy} 是物理学的基石：
\begin{equation}
E = mc^2 \label{eq:energy}
\end{equation}

如表 \ref{tab:data} 所示：
\begin{table}[h]
\centering
\caption{实验数据}
\label{tab:data}
\begin{tabular}{cc}
\toprule
变量A & 变量B \\
\midrule
1 & 2 \\
3 & 4 \\
\bottomrule
\end{tabular}
\end{table}
```
```bash
latexmk -xelatex -halt-on-error welcome.tex
```

✅ **自查**：PDF 里公式显示 (1)、表格显示 1，正文引用处是数字而不是 `??`。
