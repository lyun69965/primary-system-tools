## 实例 2：注册 score-badge 命令

🎯 **练什么**：使用 `pyproject.toml` 注册命令行入口。

📝 **任务**：让 `score-badge --score 95` 输出 `badge: A`。

💡 **思路**：`argparse` 解析参数；命令入口写成“模块:函数”。

🔧 **参考**：

```bash
cd "$(xdg-user-dir DESKTOP)/week3-practice"
cp -r ex01-scorebadge ex02-scorebadge-cli
cd ex02-scorebadge-cli
nano src/scorebadge/cli.py
```

```python
import argparse
from scorebadge.core import badge


def main():
    parser = argparse.ArgumentParser()
    parser.add_argument("--score", required=True, type=int)
    args = parser.parse_args()
    print(f"badge: {badge(args.score)}")
```

创建配置：

```bash
nano pyproject.toml
```

```toml
[build-system]
requires = ["setuptools>=68"]
build-backend = "setuptools.build_meta"

[project]
name = "scorebadge-25120014018"
version = "0.1.0"

[project.scripts]
score-badge = "scorebadge.cli:main"
```

检查：

```bash
PYTHONPATH=src python3 -c "from scorebadge.cli import main; print(callable(main))"
sed -n '1,100p' pyproject.toml
```

✅ **自查**：输出 `True`，入口指向 `scorebadge.cli:main`，项目名包含自己的学号。

## 实例 11：观察一次参数更新

🎯 **练什么**：理解 `zero_grad()`、`backward()`、`step()`。

📝 **任务**：只训练一步，比较更新前后的 weight。

💡 **思路**：清梯度、计算梯度、更新参数，三步缺一不可。

🔧 **参考**：

```powershell
notepad .\week3-practice-local\pytorch\one_step.py
```

```python
import torch
from torch import nn

torch.manual_seed(20260901)
x = torch.linspace(-1, 1, 101).reshape(-1, 1)
y = -2 * x + 5
model = nn.Linear(1, 1)
loss_fn = nn.MSELoss()
optimizer = torch.optim.SGD(model.parameters(), lr=0.1)

print("before:", model.weight.item())
loss = loss_fn(model(x), y)
optimizer.zero_grad()
loss.backward()
print("gradient:", model.weight.grad.item())
optimizer.step()
print("after:", model.weight.item())
```

```powershell
python .\week3-practice-local\pytorch\one_step.py
```

✅ **自查**：梯度不是 0，before 和 after 不相同。

## 实例 12：完整可复现训练

🎯 **练什么**：完成训练循环、评估并验证重复运行结果一致。

📝 **任务**：使损失小于 `0.001`，weight 接近 `-2`，bias 接近 `5`。

💡 **思路**：训练后切换 `eval()`；在 `no_grad()` 中重新计算最终损失。

🔧 **参考**：

```powershell
notepad .\week3-practice-local\pytorch\train_complete.py
```

```python
import torch
from torch import nn

torch.manual_seed(20260901)
x = torch.linspace(-1, 1, 101).reshape(-1, 1)
y = -2 * x + 5
model = nn.Linear(1, 1)
loss_fn = nn.MSELoss()
optimizer = torch.optim.SGD(model.parameters(), lr=0.1)

model.train()
for _ in range(250):
    prediction = model(x)
    loss = loss_fn(prediction, y)
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()

model.eval()
with torch.no_grad():
    prediction = model(x)
    loss = loss_fn(prediction, y)
    print(f"final loss: {loss.item():.8f}")
    print(f"weight: {model.weight.item():.6f}")
    print(f"bias: {model.bias.item():.6f}")
```

```powershell
python .\week3-practice-local\pytorch\train_complete.py | Set-Content .\week3-practice-local\pytorch\run1.txt
python .\week3-practice-local\pytorch\train_complete.py | Set-Content .\week3-practice-local\pytorch\run2.txt
Get-Content .\week3-practice-local\pytorch\run1.txt
Compare-Object (Get-Content .\week3-practice-local\pytorch\run1.txt) (Get-Content .\week3-practice-local\pytorch\run2.txt)
```

✅ **自查**：损失小于 `0.001`，参数接近目标；`Compare-Object` 没有输出。
